# 日本ロードサイド店舗のブランド看板制作プロセス

`くらし館`、`まちポート`、`グリルバンズ`を基準品質とする。ロゴ画像を一枚作って全看板へ貼るのではなく、ブランドの設計と看板の用途を分離する。

## 1. ブランドの立ち位置を一文で決める

- 業態、価格帯、主な客、立地、想定年代を書く。
- 他ブランドと色、輪郭、書体、情報量のうち最低二つを変える。
- 業種を直接描いただけの「家」「雲」「笑顔」のような汎用アイコンは避ける。

## 2. マスター要素を登録する

`src/store/viewer/sign-brands.ts` の `PILOT_BRANDS` に、固定ID、名称、短縮名、業態表示、英字名、5色、書体を登録する。IDは生成側とレンダラーを結ぶ契約なので変更しない。

マークは同ファイルのCanvasパスで定義する。CanvasはGPUテクスチャへの最終ラスタライズにだけ使い、形状は解像度に依存しない座標で保持する。外部SVGを採用する場合も、同じマーク関数から描画できるようにする。

## 3. 用途別ロックアップを作る

必ず次を同時に設計する。

- `fascia`: 横長の看板帯。店名を主役にして余白を残す。
- `wall`: 独立壁面看板。マークと店名を一組にする。
- `pylon`: 道路向け。短縮名、24H、主要サービスを必要に応じて加える。
- `blade`: 袖看板。マークまたは短縮名まで削る。
- `rooftop`: 遠距離用。細かい副情報を載せない。
- `menu`: 販促物。ブランド識別と商品情報を分離する。

`drawPilotBrand()` 内で役割を分岐し、同じ完成画像を拡縮して流用しない。

### ポール看板の文字比率

日本のロードサイド型は小さなキャプションを並べず、ブランド面とサービス面を積層する。店名または主サービスの文字幅は各パネルの85〜94%、文字高はパネル高の35〜60%を基準にする。ホームセンター系は巨大な記号面＋店名面＋商品分野面、コンビニ系は色帯＋店名面＋「酒・たばこ」「銀行ATM」などの独立面とする。外照式では上部レールと2〜3灯の投光器も一体で確認する。

サービス・誘導文言は日本語を主表示にする。「ドライブスルー」「お持ち帰り」「入口」「24時間営業」などを大きく置き、`DRIVE THRU` や `TAKE OUT` はブランド意匠として必要な場合だけ小さな補助表記に留める。

## 4. 校正ページで比較する

`pnpm dev` 後に `http://localhost:5180/signage.html` を開く。次を確認する。

- 3ブランドがモノクロのシルエットでも区別できる。
- 横長、縦長のどちらでも主役が一つに見える。
- 遠目で店名を読めなくても業態とブランドを推測できる。
- 小さい袖看板に細い文字や副情報が残っていない。
- 余白が額縁幅より狭くなっていない。

## 5. 3D店舗で確認する

`http://localhost:5180/store.html` で対象presetとロゴIDを選び、道路距離、駐車場距離、近距離、斜め方向から確認する。版下の問題と、筐体・照明・配置の問題を混同しない。

## 6. 検証して追加する

```bash
pnpm typecheck
pnpm vitest run src/store/viewer/sign-brands.test.ts src/store/gen/store.test.ts
pnpm build
```

新ブランドは、一覧校正と3D確認の両方を通してからauto選択poolへ追加する。
